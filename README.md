## 如何使用这个仓库

### 1. 每完成一个作业/项目就立刻归档
建议每个作业单独建文件夹，并包含：

```
assignment-or-project-name/
├── README.md          # 必写：题目、要求、你的思路、结论、亮点
├── data/              # 数据（注意脱敏）
├── code/              # SQL / Python / R 等代码
├── output/            # 图表、结果表、报告 PDF
└── slides/            # 如果有汇报 PPT
```

### 2. README 模板（每个项目都建议写）

```markdown
# 项目标题

**课程 / 来源**：xxx  
**完成时间**：2026-xx  
**工具**：SQL / Python (Pandas) / Excel / ...

## 1. 问题与目标
简要说明作业要求或你自己定义的问题。

## 2. 数据说明
数据来源、字段、样本量、处理方式。

## 3. 分析方法
用了哪些方法、为什么这样分析。

## 4. 主要发现
关键结论（最好配合图表）。

## 5. 建议 / 启示
对业务或研究的启示。

## 6. 可复现说明
如何运行代码、依赖环境。
```

### 3. 作品集展示建议
- 把最能体现分析能力的 2–4 个项目放在最显眼位置
- 每个项目的 README 用**中英文**写更好（方便申研）
- 突出「问题定义 → 分析过程 → 洞察与建议」完整闭环

## 快速开始

1. 克隆仓库
   ```bash
   git clone https://github.com/yanbei905-commits/coursework-portfolio.git
   cd coursework-portfolio
   ```

2. 新建作业文件夹，按上面的结构放文件

3. 写好该作业的 README.md

4. 提交并推送

有新作业需要我帮你整理结构、写项目描述、检查代码或改英文版 README，随时告诉我。
